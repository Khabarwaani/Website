Decoupled Operating Architecture

The Specialized Multi-Agent Operating Mesh

Monolithic models hallucinate facts and drift visually. Khabarwaani distributes production across specialized micro-agents over a structured event bus.

Agent 01 · Signal Intake

Ingestor Agent

Monitors official gazettes, court orders, and regulatory wires around the clock. Extracts atomic claims with strict origin metadata.

Agent 02 · Journalistic Firewall

Fact Verification Auditor

Cross-references claims against primary source records. Scores factual certainty and rejects unverified speculation before scripting begins.

Agent 03 · Engagement & Wit

Scriptwriter & Humor Agent

Translates complex policy into 10s–60s spoken vertical arcs using relatable analogies, witty punchlines, and zero fluff.

Agent 04 · Visual Blocking

Scene Staging Parameterizer

Converts script lines into machine-readable JSON scene parameters encoding camera angles, eye-lines, facial seeds, and timing bounds.

Agent 05 · Compute Mesh

Model Router & Render Mesh

Dispatches shot specs to optimal video, SVG motion, and regional neural voice models. Enforces isolated sub-clip repair on failures.

Agent 06 · Quality Assurance

Telemetry & QA Agent

Audits finished clips for audio sync, pacing, and subtitle legibility. Feeds audience retention data back into the scripting mesh.

Resource Optimization & Speed

Dynamic Model Routing & Granular Quality Control

A production studio cannot run top-tier models for every second of video. Tasks are routed dynamically based on scene complexity and latency.

Scene Type Routing Strategy Engineering Rationale
Simple Talking Head High-speed, low-latency model adapter Prioritizes fast lip-sync alignment and rapid turnaround under 2 minutes.
Complex 2-Person Interaction High-fidelity generative model Preserves multi-character spatial continuity, eye-lines, and natural turn-taking.
Data / Infographic Explainer Deterministic SVG & kinetic typography engine Eliminates hallucination risk; programmatic numeric visual rendering.
Vernacular Speech Synthesis Dialect-specialized neural TTS Natural spoken cadence with colloquial pause modulation in regional Indian languages.
Targeted Sub-Clip Repair:

If an individual 3-second shot fails quality checks, the orchestrator re-renders only that specific sub-clip. It does not regenerate the entire video.

Machine-Readable Scene Parameters

Ambiguous Natural Language Prompt

Leaves spatial blocking, timing, and continuity to chance.

"Two people discuss the news in an office."

Result: Identity swaps, random camera angles, broken continuity.

Khabarwaani Production Spec (JSON)

Structured parameterization encoding characters, blocking, and timing constraints.

{
  "scene_id": "shot_03_discussion",
  "characters": [
    {"id": "char_A", "role": "lead_anchor", "face_seed": "ak_4021"},
    {"id": "char_B", "role": "analyst", "pose": "standing_profile"}
  ],
  "camera": {"angle": "medium_two_shot", "lens_mm": 50, "focal_lock": "char_A"},
  "dialogue_timeline": [
    {"speaker": "char_A", "start_s": 0.0, "end_s": 3.8, "gaze": "char_B"},
    {"pause_ms": 350, "pacing": "natural_breath"},
    {"speaker": "char_B", "start_s": 4.15, "end_s": 8.5, "gaze": "char_A"}
  ]
}

Result: Deterministic blocking, exact speech pauses, and seamless cut transitions.

Zero Hallucination Standard

Journalistic Grounding & Primary Records Traceability

News demands far greater precision than entertainment. Every sentence in a Khabarwaani reel is anchored to an official record before rendering.

Step 1
Primary Source
Official Gazette / Court Order / Regulatory Wire
Step 2
Atomic Claim
Isolated verifiable fact with confidence check
Step 3
Script Sentence
15s–60s spoken line with relatable analogy
Step 4
Video Scene
Corresponding visual shot and typographic overlay
Fast Live Corrections & Updates:

Every script line maps to a primary source node. Breaking updates or clarifications can be patched in minutes by updating only that node, without rebuilding the story.
